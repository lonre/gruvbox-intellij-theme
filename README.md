# Gruvbox Islands Theme for JetBrains IDEs

An Islands-native edition of the Gruvbox theme for JetBrains IDEs 2025.3 and later.

[Download Gruvbox Islands - Theme from JetBrains Marketplace](https://plugins.jetbrains.com/plugin/34175).

Gruvbox is heavily inspired by badwolf, jellybeans, and Solarized. It combines warm retro colors with clear contrast and comfortable long-session readability.

The plugin includes six variants:

- Gruvbox Islands Dark Hard
- Gruvbox Islands Dark Medium
- Gruvbox Islands Dark Soft
- Gruvbox Islands Light Hard
- Gruvbox Islands Light Medium
- Gruvbox Islands Light Soft

This plugin is a fork of the existing [Gruvbox - Theme](https://plugins.jetbrains.com/plugin/20558) plugin, adapted for the Islands UI.
